# Linux Administration Lab

A practical Linux Administration learning and interview preparation repository.

## Repository Sections

| Directory | Purpose |
|---|---|
| 01_notes | Linux concepts and technical documentation |
| 02_commands | Linux commands and practical usage |
| 03_interview_questions | Topic-wise interview preparation |
| 04_production_incidents | Real-world troubleshooting scenarios |

- Linux Administration
- Filesystem and Storage Management
- Process and Service Management
- Networking and Security
- Shell Scripting and Automation
- Performance Monitoring and Troubleshooting
- Virtualization and Containers
- Cloud Operations and DevOps

## Environment

- OS: RHEL / CentOS

- Version Control: Git
